# Design

Proposals written before building, so the approach can be argued with while it is still
cheap to change.

One file or folder per proposal; move it to `../impl/` once it ships.

| | |
|---|---|
| [digitalmeh-migration.md](digitalmeh-migration.md) | Move `digitalmeh.net` off WordPress to Jekyll, so the AWS box can be retired |

Worth stating in a proposal: what problem it solves, what was measured, which alternatives
were rejected and on what numbers, and what would make it a bad idea.
