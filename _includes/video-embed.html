{%- comment -%} Responsive YouTube embed. Deliberately framework-independent. The site currently loads Bootstrap 4.5, whose aspect-ratio helper is .embed-responsive; Bootstrap 5 renamed it to .ratio, and chulapa 2.x may switch versions. The padding-bottom technique below works regardless and cannot silently collapse if a class disappears. Usage: {% include video-embed.html id="VIDEOID" title="Title" %} {% include video-embed.html id="VIDEOID" title="Title" ratio="9x16" maxwidth="360px" %} {%- endcomment -%} {%- assign ratio = include.ratio | default: "16x9" -%} {%- if ratio == "9x16" -%}{%- assign pad = "177.78%" -%}{%- else -%}{%- assign pad = "56.25%" -%}{%- endif -%} {%- assign maxw = include.maxwidth | default: "640px" -%}
