# Tournament Report Template

This is for a **personal** report — your own story of playing in an
event (deck choice, prep, round-by-round matches, how you did). If
you're writing an organizer's overview of the whole event instead
(metagame breakdown, top 8, other players' decklists), ask about the
tournament-writeup template instead.

You don't need to know git, GitHub, or anything technical — just follow
these steps, then zip this whole folder back up and send it back.

## What's in here

```
README.md                                       <- this file
_posts/
  YYYY-MM-DD-your-tournament-report-title.md     <- your write-up goes here
assets/
  images/
    avatars/                                     <- optional: your author photo goes here
    YYYY/MM/DD/
      01.jpg, ...                                <- your photos go here
      top8/                                       <- optional: your top-8 photo, if you made it
  files/
    YYYY/MM/DD/
      Example Player - Example Deck.txt          <- sample decklist file
```

## Steps

1. **Open `_posts/YYYY-MM-DD-your-tournament-report-title.md`** in a
   plain text editor (Notepad, TextEdit, VS Code — **not Microsoft
   Word**, which adds hidden formatting that breaks things).

2. **Rename the file itself**: replace `YYYY-MM-DD` with the date and
   `your-tournament-report-title` with a short, lowercase,
   dash-separated title. Example: `2026-08-08-my-summer-showdown-run.md`.

3. **Fill in the top section** (between the two `---` lines). Most of
   it is already filled in with the site's normal defaults — you really
   only need to touch title, date, and your author info. Detailed notes
   are inside the file itself as a comment block.

   First time writing for us? Add a small square photo of yourself to
   `assets/images/avatars/` (see the placeholder file there for naming
   tips) and point the `avatar:` line at it. Written for us before? Just
   reuse your existing avatar if you know the path, or ask.

4. **Write your report.** The template gives you a skeleton — intro,
   prep, a section per day, a subsection per round, a sub-subsection per
   game. Copy/paste the "Round" and "Game" blocks as many times as you
   played, and delete whatever doesn't apply to your event. It's your
   story — reorganize however fits how things actually went.

5. **Add your photos**: put them in `assets/images/YYYY/MM/DD/` —
   rename that `YYYY/MM/DD` to match the date you used in the post
   filename. Simple lowercase filenames, no spaces.

6. **Add your decklist**: make a plain `.txt` file in
   `assets/files/YYYY/MM/DD/` named `Your Name - Your Deck.txt`. One
   card per line as `QUANTITY Card Name`, a blank line, then any
   sideboard cards the same way. There's a real example already in that
   folder — open it to see the exact format. Reference it in the
   "Decklist" section of the post — the template shows the exact line
   to copy.

7. **When you're done**, select this whole folder (the one with this
   README in it) and compress it into a .zip file, then send it back.
   Don't worry about anything else — formatting it for the website is
   handled on this end.

Questions? Just ask — no need to get it perfect.
