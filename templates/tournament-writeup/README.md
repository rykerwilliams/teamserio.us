# Tournament Write-Up Template

Thanks for writing this up! You don't need to know git, GitHub, or
anything technical — just follow these steps, then zip this whole folder
back up and send it back.

## What's in here

```
README.md                                    <- this file
_posts/
  YYYY-MM-DD-your-tournament-title.md         <- your write-up goes here
assets/
  images/
    avatars/                                 <- optional: your author photo goes here
    YYYY/MM/DD/
      banner.jpg, 01.jpg, ...                 <- general photos
      top8/                                   <- top 8 player photos
      round-photos/                           <- optional side-by-side gallery
      candids/                                <- optional closing photo gallery
  files/
    YYYY/MM/DD/
      Example Player - Example Deck.txt       <- sample decklist file
```

## Steps

1. **Open `_posts/YYYY-MM-DD-your-tournament-title.md`** in a plain text
   editor (Notepad, TextEdit, VS Code — **not Microsoft Word**, which
   adds hidden formatting that breaks things).

2. **Rename the file itself**: replace `YYYY-MM-DD` with the tournament's
   date and `your-tournament-title` with a short, lowercase,
   dash-separated title. Example: `2026-08-08-summer-showdown.md`.

3. **Fill in the top section** (between the two `---` lines) — title,
   subtitle, date, and your name. Detailed notes are inside the file
   itself as a comment block.

   First time writing for us? Add a small square photo of yourself to
   `assets/images/avatars/` (see the placeholder file there for naming
   tips) and point the `avatar:` line at it. Written for us before? Just
   reuse your existing avatar if you know the path, or ask. Don't want
   an avatar at all? Delete the whole `avatar:` line.

4. **Write your report**, replacing the bracketed `[placeholder text]`
   sections: intro, metagame breakdown, top 8, round results, and
   closing thank-yous. Everything is plain text/lists — copy the
   patterns already in the file.

5. **Add your photos**: put general photos in
   `assets/images/YYYY/MM/DD/`, top-8 player photos in the `top8`
   subfolder — rename that `YYYY/MM/DD` to match the same date you used
   for the post filename. Simple lowercase filenames, no spaces.

6. **Add decklists**: for each deck you want to include, make a plain
   `.txt` file in `assets/files/YYYY/MM/DD/` named
   `Player Name - Deck Name.txt`. One card per line as
   `QUANTITY Card Name`, a blank line, then any sideboard cards the same
   way. There's a real example already in that folder — open it to see
   the exact format, then copy the pattern for each deck. Reference each
   one in the "Decklists" section of the post — the template shows the
   exact line to copy.

7. **Optional — photo galleries**: the `round-photos` and `candids`
   folders are examples of side-by-side photo galleries (3 photos next
   to each other instead of stacked). If you don't want them, just
   delete those folders and the matching lines in the post — entirely
   optional.

8. **When you're done**, select this whole folder (the one with this
   README in it) and compress it into a .zip file, then send it back.
   Don't worry about anything else — formatting it for the website is
   handled on this end.

Questions? Just ask — no need to get it perfect.
