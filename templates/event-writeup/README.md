# Event Write-Up Template

Thanks for writing this up! You don't need to know git, GitHub, or
anything technical — just follow these steps, then zip this whole folder
back up and send it back.

## What's in here

```
README.md                                 <- this file
_posts/
  YYYY-MM-DD-your-event-title.md          <- your write-up goes here
assets/
  images/
    avatars/                             <- optional: your author photo goes here
    YYYY/MM/DD/
      01.jpg, 02.jpg, ...                 <- your photos go here
      some-moment/                        <- optional: photos for a side-by-side gallery
```

## Steps

1. **Open `_posts/YYYY-MM-DD-your-event-title.md`** in a plain text editor
   (Notepad, TextEdit, VS Code — **not Microsoft Word**, which adds hidden
   formatting that breaks things).

2. **Rename the file itself**: replace `YYYY-MM-DD` with the event's date
   and `your-event-title` with a short, lowercase, dash-separated title.
   Example: `2026-08-08-summer-showdown.md`.

3. **Fill in the top section** (between the two `---` lines) — title,
   subtitle, date, and your name. Detailed notes are inside the file
   itself as a comment block.

   First time writing for us? Add a small square photo of yourself to
   `assets/images/avatars/` (see the placeholder file there for naming
   tips) and point the `avatar:` line at it. Written for us before? Just
   reuse your existing avatar if you know the path, or ask. Don't want
   an avatar at all? Delete the whole `avatar:` line.

4. **Write your report** below that, replacing the bracketed
   `[placeholder text]` with your own words. It's just plain paragraphs —
   no special formatting needed unless you want to add photos or
   headings (a few examples are already in the file).

5. **Add your photos**: put every photo file inside
   `assets/images/YYYY/MM/DD/` — rename that `YYYY/MM/DD` folder to match
   the same date you used for the post filename. Give each photo a
   simple name with no spaces, like `01.jpg` or `trophy.jpg`. Then
   reference each one in the text where it belongs — the template shows
   you the exact format to copy.

6. **Optional — side-by-side photo galleries**: if you have 3 related
   photos you'd like shown next to each other instead of stacked, see
   the instructions inside the post template and the example
   `some-moment` folder. If you skip this, just delete that folder and
   the related line in the post — it's entirely optional.

7. **When you're done**, select this whole folder (the one with this
   README in it) and compress it into a .zip file, then send it back.
   Don't worry about anything else — formatting it for the website is
   handled on this end.

Questions? Just ask — no need to get it perfect.
