Where this comes from

The lists live in rykerwilliams/type1, beside the B&R history behind the timeline, one file per event with its source. They are copied from the original event coverage — Wizards, the Eternal Weekend organizers, the magazines and newsgroups of the 1990s — and, only where no original survives, from Jimmy’s collection on Deckbox. Where a source printed a list wrong, a second source fixed it and a note on the event says so.

Something wrong, or missing? A miscounted card, a wrong placing, a dead or mis-cited source, a lost list you have a copy of: here’s how to fix it. An issue with a source is enough.
